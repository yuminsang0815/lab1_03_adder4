# 실험 전 레포트: 4비트 가산기

작성일 2026-09-19.

## 목적과 예상값

두 4비트 입력 `a[3:0]`, `b[3:0]`에 대해 5비트 확장 덧셈을 수행하여 4비트 합 `s[3:0]`과 1비트 최상위 올림수 `cout`을 구합니다. top은 `adder_4bit`입니다. 산술 관계는 $a + b = 16 \times cout + s$입니다.

| a | b | cout | s | 비고 |
|---:|---:|---:|---:|---|
| 0000 (0) | 0000 (0) | 0 | 0000 (0) | 최소 입력 합 |
| 0001 (1) | 1111 (15) | 1 | 0000 (0) | 올림수 발생 및 하위 비트 순환 |
| 1000 (8) | 0000 (0) | 0 | 1000 (8) | 상위 비트 덧셈 |
| 1111 (15) | 1111 (15) | 1 | 1110 (14) | 최대 입력 합 (30) |

## 환경과 입력 파일

Windows, Git 2.55.0, VS Code 1.136.1, XSim 2026.1을 사용했습니다. 공개 템플릿의 커밋 `740aef5`를 공백이 있는 별도 폴더에 새로 clone했습니다. `LAB1.code-workspace`는 `vivado_2026_1/03_adder4`를 PROJECT, `common`을 COMMON으로 연결합니다.

[RTL](../../src/adder_4bit.v), [TB](../../sim/tb_adder_4bit.sv), [XDC](../../constraints/adder_4bit.xdc)를 사용했습니다. TB top은 `tb_adder_4bit`이며 루프 변수 n을 0부터 255까지 10ns 간격으로 인가하여 상위 4비트는 a, 하위 4비트는 b에 연결합니다. 정수 연산 기대값과 출력을 비교하여 오류 시 `$fatal`을 호출하고, 256건 검사 완료 시 PASS 출력 후 2560ns에 종료합니다.

## 실행과 관찰

VS Code 새 창에서 workspace를 열고 slang-server와 VaporView를 활성화했습니다. 저장 후 Terminal → Run Task...의 Check tools, Simulate를 실행하고 Open waveform으로 VCD를 열었습니다. `a,b,cout,s`를 추가하고 Zoom to Fit와 ns 단위를 선택했습니다.

실제 [VS Code 작업 실행 로그](../../evidence/03/vscode/simulation.txt)에서 `LAB1_PASS adder_4bit cases=256`과 2560ns 종료를 확인했습니다.

| 구간(ns) | a (hex) | b (hex) | cout, s (hex) | 해석 |
|---|---|---|---|---|
| 0–10 | 0 | 0 | 0, 0 | 0+0=0 |
| 310–320 | 1 | F | 1, 0 | 1+15=16: cout 전이 및 s=0 관측 |
| 1280–1290 | 8 | 0 | 0, 8 | 8+0=8: 올림수 없음 |
| 2550–2560 | F | F | 1, E | 15+15=30: 최댓값 정상 연산 |

전환 순간 대신 구간 중간에서 커서를 읽었습니다. 파형만 눈으로 맞아 보이는 것에 더해 자동 비교 256건과 정상 종료를 함께 확인했습니다.

## 보드 실험 계획

DIP1\~4(a[3:0]), DIP5\~8(b[3:0]), LED1(cout), LED2\~5(s[3:0]), LVCMOS33입니다. Vivado에서 같은 TB를 실행한 다음 bit를 생성하고 보드에 다운로드합니다. 특히 a=1, b=15 인가 시 cout LED1만 켜지고 s LED2\~5가 모두 꺼지는 오버플로 전이 동작을 사진·영상에 담을 계획입니다.
